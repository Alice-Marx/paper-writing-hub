# Research-Writing-Skill

> 上游仓库：**<https://github.com/norman-bury/research-writing-skill>**（v3.1.0）
> 许可：MIT

新手全流程写作系统 19 模块：头脑风暴→章节规划→逐章写作→质量门控→LaTeX（入口技能 research-writing-assistant）。

**本目录是占位链接页**：运行安装器后，此处会填充该项目的全量副本（`git clone --depth 1`，不裁剪）：

```bash
npx paper-writing-hub              # 全部安装
npx paper-writing-hub --select rws   # 只装这一个
```

使用指南见同目录 `../research-writing-skill.md`。
